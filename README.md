# ucsi

A Flutter project of LQ-Online hotel mobile app.

## Objective

To digitize and streamline the process of managing lab equipment and service quotations through an internal system with customizable templates and access controls.

## Features
- Book hotel room
- Provide rating
- Order food

## Tech Stack
- Flutter (Dart)
- Html
